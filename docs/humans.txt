/* WHAT THIS IS */
  EigenTrace — an autonomous instrument measuring how five frontier language models
  reshape live breaking news, using deterministic linear algebra on frozen embeddings,
  with no model judging another. Built on one consumer GPU by one person.

/* FLAGSHIP STUDY */
  LLM Consensus Geometry: The 2026 Iran War
  510 classified stories · 85 days · five frontier models
  The content axis snapped from erased to preserved as the war escalated.
  The consensus outlier handed off from Claude to Grok.
  https://eigentrace.ai/llm-consensus-geometry-iran-2026
