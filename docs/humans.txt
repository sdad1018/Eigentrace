/* WHAT THIS IS */
  EigenTrace — an autonomous instrument measuring how five frontier language models
  reshape live breaking news, using deterministic linear algebra on frozen embeddings;
  no language model grades another in the measurement path (retention, divergence,
  density), and the model-in-the-loop steps are labelled as such. Built on one consumer
  GPU by one person.

/* FLAGSHIP STUDY */
  Unsourced Specifics: The 2026 Iran War
  455 stories · May-September 2026 · five frontier models
  When the input mentioned the Strait of Hormuz, three of the five supplied a
  share-of-world-oil figure that was not in it. ChatGPT did so in 0 of 192.
  https://eigentrace.ai/llm-consensus-geometry-iran-2026
